This is a **template**. Copy this file to a new name (or use **Notes → New Note** in the
admin panel), change the text and set `draft: true` to publish it.

Inline math uses single dollars, e.g. the Schwarzschild shadow radius $R_{\rm sh} = 3\sqrt{3}\,M$.
Display math uses double dollars:

$$
\Omega_r^2 = \Omega_\varphi^2 \left(1 - \frac{6M}{r}\right), \qquad \Omega_\varphi^2 = \frac{M}{r^3}.
$$

## A heading

- Lists, **bold**, _italic_, [links](https://example.org) and `code` work as in any Markdown.
- The Uzbek version of a note has the same file name in `src/content/notes/uz/`.
